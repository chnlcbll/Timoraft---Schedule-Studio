# Privacy Policy for Timoraft — Schedule Studio

Last updated: September 8, 2026

Timoraft — Schedule Studio ("Timoraft") is a local-first Chrome extension for creating, comparing, saving, merging, and exporting class schedules as customizable wallpapers.

## Information Timoraft handles

Timoraft handles the following information only to provide its schedule-building features:

- Courses, sections, schedules, pinned choices, rooms, instructor names, enrollment information, and other schedule details entered by the user or imported from Archer's Hub.
- Timoraft preferences, saved schedules, wallpaper settings, and wallpaper background images selected by the user.
- Existing Archer's Hub authentication cookies, temporarily, when the user chooses to connect, search, or refresh Archer's Hub.

Timoraft does not collect financial information, health information, personal communications, precise location, browsing history, or advertising identifiers. It does not log keystrokes, mouse movements, or general browsing activity.

## How information is used

Schedule information is used to build and compare schedules, detect conflicts, calculate breaks, merge schedules, display course and enrollment details, and create wallpaper exports.

Archer's Hub authentication cookies are used only to detect an existing sign-in and authenticate requests that the user starts. Timoraft does not store copies of those cookies.

## Local storage

Schedules, preferences, imported course information, and selected wallpaper images are stored locally in the user's browser. Timoraft does not operate a developer server and does not upload this locally saved information to the developer.

## Archer's Hub

When the user chooses to search or refresh Archer's Hub, Timoraft sends the selected campus, academic term, or course request directly to [Archer's Hub](https://archershub.dlsu.edu.ph/) using the user's existing signed-in session. Archer's Hub returns course and section information needed for the requested feature. That interaction is subject to Archer's Hub's own terms and privacy practices.

Timoraft does not contact Archer's Hub unless the user starts a connection, search, import, or refresh action.

## Data sharing and sale

Timoraft does not sell user data. It does not share user data with advertisers, data brokers, analytics services, or unrelated third parties. Information is transferred to Archer's Hub only as necessary to provide a user-requested catalog feature, or when disclosure is required by law.

Timoraft's use and transfer of information is limited to providing or improving its disclosed schedule-building purpose and complies with the Chrome Web Store User Data Policy, including the Limited Use requirements.

## Security

Requests to Archer's Hub use HTTPS. Authentication information is used only for the requested Archer's Hub interaction and is not publicly disclosed.

## Retention and deletion

Locally saved information remains in the user's browser until the user removes saved content, clears Timoraft's extension data, or uninstalls Timoraft. Timoraft's developer does not retain a separate server-side copy.

## Changes to this policy

This policy may be updated if Timoraft's features or information practices change. The latest version will be posted at the same public URL with a revised “Last updated” date.

## Contact

For privacy questions, contact the developer through the [Timoraft issue tracker](https://github.com/chnlcbll/Timoraft---Schedule-Studio/issues) or the support contact shown on Timoraft's Chrome Web Store listing.
